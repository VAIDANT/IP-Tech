# iPTECH Coming Soon — deployment guide

This is a static website. You can host it on GoDaddy hosting, Netlify, Vercel, Cloudflare Pages, GitHub Pages, or any standard web host.

## 1) Connect the email signup to Supabase

The site is already wired for a Supabase table. You only need a free Supabase project and two public values.

### Create the table
Open Supabase -> SQL Editor and run:

```sql
create table if not exists public.subscribers (
  id bigint generated by default as identity primary key,
  email text not null unique,
  source text default 'coming-soon',
  created_at timestamptz not null default now()
);

alter table public.subscribers enable row level security;

create policy "Allow anonymous newsletter signups"
on public.subscribers
for insert
to anon
with check (true);
```

Do NOT create a public SELECT policy. That keeps the subscriber list unreadable from the public website.

### Add your public keys
In Supabase -> Project Settings -> API, copy:
- Project URL
- anon/public API key

Open `config.js` and replace:

```js
SUPABASE_URL: "YOUR_SUPABASE_URL",
SUPABASE_ANON_KEY: "YOUR_SUPABASE_ANON_KEY"
```

The Supabase anon key is a public client key. Security comes from Row Level Security, which is why the table policy above only allows inserts.

### View/export signups
Supabase -> Table Editor -> `subscribers`.
You can filter, sort, and export the list as CSV from one place.

## 2) Host with a GoDaddy domain

Owning a GoDaddy domain and owning GoDaddy web hosting are separate things.

### If you have GoDaddy cPanel / Web Hosting
Upload the CONTENTS of this folder into `public_html` using File Manager or FTP. Your main file must remain named `index.html`.

### If you only own the domain
A simple option is Netlify, Vercel, or Cloudflare Pages. Deploy this folder there, then follow that platform's custom-domain screen and update the DNS records in GoDaddy.

## 3) Before publishing

- Connect Supabase in `config.js`.
- Test one signup and confirm it appears in the `subscribers` table.
- Replace the AI CCTV scene later when official iPTECH product photography is available.
